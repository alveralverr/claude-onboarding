# Seeding the practice kit

The practice kit lives in this skill's `assets/practice-kit/` directory. During the warm-up, copy it into the assistant's working folder so they have safe material to act on.

## What to do

1. **Find the assistant's working folder.** This is the project/folder Cowork is currently working in. If none is set, help them set one (or create a `Cowork Practice Kit` folder) before seeding — Cowork needs a place to read and write.
2. **Create a clearly named subfolder** so practice files don't clutter their real work — e.g. `Cowork Practice Kit/` inside their working folder.
3. **Copy all five files** (four samples + a README) from `assets/practice-kit/` into that subfolder:
   - `README-practice-kit.md`
   - `sample-client-inbox.md`
   - `sample-meeting-notes.md`
   - `sample-receipts.md`
   - `sample-week.md`
   Use whatever file tools you have in the environment (copy them, or read each asset and write it into the folder). The contents must match the bundled files exactly — don't regenerate them from memory, so every assistant practices on the same safe material.
4. **Tell the assistant what landed and where**, and point them to the Working folder panel so they *see* the files appear. That moment — watching Cowork write to their folder — is the demonstration.

## Notes

- Everything in the kit is fictional. Reassure the assistant there's no client risk.
- If the assistant already ran this skill before and the kit exists, don't duplicate it — just confirm it's there and move on.
- At the end of the session, offer to delete the practice folder if they don't want it lingering.
- If you genuinely can't write to their folder (permissions, no folder set), don't fake it — explain what's blocking and help them resolve it, or fall back to coaching them to create one sample file themselves as the first hands-on action.
