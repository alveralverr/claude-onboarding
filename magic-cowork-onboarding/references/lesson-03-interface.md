# Lesson 3 — What you need + the Cowork interface

## Learning objectives

- Know the minimum requirements to run Cowork.
- Be able to find every key part of the Cowork desktop app — the home screen and inside a running task.

## Minimum requirements (what you need)

- **Google Chrome**
- Your **magicassistant.ai** webmail (receive login credentials from your ALs)
- Your **Claude.ai** invite (follow link from inside your webmail inbox)
- **macOS 11 (Big Sur)** or higher, or **Windows 10** or higher
- **Claude desktop** installed (claude.com/download)
- Your webmail account signed into Claude desktop

*(Teaching note: There are two setup videos on the web guide — a local screen-recording walkthrough and a YouTube overview. The guide notes: "Setup demo will be updated soon. Getting the Claude invite link from your magicassistant.ai webmail is the correct and current process." Don't reference the videos as something to watch here; teach the content directly.)*

## The Cowork desktop app, explained

Every part of the screen, from the mode switcher to your project folder. Below are the two screens of the app.

### Screen 1 — Home / new task

The home screen breaks into two zones: the **Sidebar** and the **Composer & Main Area**.

1. **Window bar** — Close or resize the app, collapse the sidebar, and search across your chats and tasks.
2. **Mode switcher** — Switch between Chat, Cowork, and Code. Cowork is the mode that takes on whole tasks for you.
3. **New task** — Start a fresh Cowork task with a clean slate.
4. **Projects** — Workspaces tied to a folder on your computer, each with its own files, instructions, and memory.
5. **Scheduled** — Tasks Claude runs automatically on a cadence you set — daily, weekly, or monthly.
6. **Live artifacts** — Dashboards and trackers Claude builds that refresh with current data each time you open them.
7. **Customize** — Add skills and connectors, set instructions, and manage your plugins and settings.
8. **Recents** — Your recent tasks and chats. Click any one to pick up where you left off.
9. **Account & profile** — Your name, plan, and settings live here. Sign out from this menu.
10. **What's new** — Release notes for the latest Claude features and updates.
11. **Home greeting** — Your starting point each time you open a new task.
12. **Usage & safety banner** — Shows your current usage allowance and a link to learn how to use Cowork safely.
13. **Prompt input field** — Type what you want done here. Be specific about the output and where to save it.
14. **Add context** — Attach files, screenshots, or other context to your prompt with the plus button.
15. **Dictation** — Speak your prompt out loud instead of typing it.
16. **Work in a project** — Pick the folder Claude reads from and saves finished work back to.
17. **Model & reasoning** — Choose the Claude model and how hard it thinks. Higher effort uses more of your usage limit.
18. **Project picker** — Search your projects, create a new one, or point Claude at a different folder.

### Screen 2 — Inside a running task

What you'll see once a task is running — Claude's replies, the tools it uses, the skills it suggests, and the panel that tracks its progress. Three zones: the **Conversation**, the **Composer**, and the **Task Panel**.

1. **Task title & switcher** — The name of the current task. Click the chevron to rename it, switch tasks, or start a new one.
2. **Conversation thread** — Your prompts and Claude's replies appear here, newest at the bottom — just like a chat.
3. **Tool call** — Whenever Claude runs a command or uses a tool, it shows here. Click to expand and see exactly what it did.
4. **Suggestion card** — Claude proposes a plugin or skill it thinks will help. Dismiss it with the ✕ if you don't need it.
5. **Add a plugin** — Installs a bundle of related skills (here, Marketing) so Claude can call them in this task.
6. **Skill command** — Each /skill is a ready-made task. Hit **Try it** to run one, or type its slash command yourself.
7. **Message box** — Reply, redirect, or give Claude your next instruction. Press Enter to send.
8. **Add context** — Attach files, screenshots, or other context to send along with your message.
9. **Model selector** — Switch the Claude model for this task. Heavier models use more of your usage limit.
10. **Dictation** — Speak your message out loud instead of typing it.
11. **Panel toggle** — Show or hide the right-hand panel that tracks this task.
12. **Progress** — The task's step-by-step checklist. Completed steps get ticked off so you can see what's left.
13. **Working folder** — View and open the files Claude created or edited during this task.
14. **Context** — Tracks the tools Claude used and the files it referenced while working.

## Knowledge check

**Question (multiple choice):** In the Cowork desktop app, which control do you use to pick the folder Claude reads from and saves finished work back to?

- A) The mode switcher
- B) "Work in a project" / the project picker
- C) Dictation
- D) What's new

**Correct answer: B.** "Work in a project" (and the project picker) is where you point Claude at the folder it should read from and save back to.

*(If wrong: re-explain that the mode switcher chooses Chat/Cowork/Code, while "Work in a project" is specifically about choosing the working folder. Then re-ask.)*
