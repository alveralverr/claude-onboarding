Overview

An AI canvas that generates on command.

Claude Design lives at claude.ai/design and in your Claude Desktop sidebar. It gives Claude a visual canvas alongside its chat interface. You describe what you want — a prototype, a deck, a one-pager, a dashboard — and Claude generates it as live, editable code on the right-hand canvas.

It is not a static image generator. The output is real HTML, CSS, and JavaScript you can interact with, share, and hand off directly to Claude Code for implementation.

Built under Anthropic Labs, Anthropic's experimental products group, it sits squarely in the middle of the design workflow: fast enough for first drafts, connected enough to hand off to engineering.

Claude Design now lives in your Claude Desktop sidebar. As of June 17, 2026, you can open it directly from the same app you use for Cowork — no separate browser tab needed.

How to refine

Draft → Refine → Ship.

  1. 1

    Create a project with context

    Bring brand assets, style references, and a code repo if one exists. Context up front beats correction later.

  2. 2

    Describe what you want

    Use the four-part prompt: goal, layout, content, audience.

  3. 3

    Review the first draft

    Claude generates on the canvas. Clarifying questions may appear first — answer them for a sharper result.

  4. 4

    Iterate precisely

    Chat for broad changes, inline comments for specific elements, direct text edits for copy, sliders for spacing and color.

  5. 5

    Branch a version

    Tell Claude save what we have and try a completely different approach to explore safely.

  6. 6

    Export or hand off

    Use the Export menu: common file formats, Canva handoff, or a one-click Claude Code handoff.

Known issue: inline comments can occasionally disappear before Claude reads them. If this happens, paste the comment text directly into the chat panel instead.

Brand & Design Systems

Without a design system, output is generic.

Publish one once, and every new project inherits your colors, typography, and components automatically.

Setup happens once per organization: create your org in Claude Design, upload brand and product assets (logos, palette files, code repo, decks), review what Claude extracted, then publish. The June 17, 2026 update added rebuilt design system imports straight from a GitHub repository, so a repo is now a first-class source. Teams can hold more than one system for sub-brands — use the Remix button to open a chat where Claude modifies it.

Recommended rollout order: publish the design system first, then grant team access. Rolling out access before a system exists means every user's first projects look generic.

Knowing the difference

Design shapes. Code builds.

Feature Claude Design Claude Code
Primary job Generate & refine visual drafts on a canvas Edit files, run commands, work on codebases
Where it runs claude.ai/design + Claude Desktop sidebar Terminal, IDE, desktop app, browser
What it outputs Live HTML/CSS/JS canvas, exportable files Edited code files, executed commands
Code repo access Read-only (for brand/design-system context) Full read + write + execute
Handoff Exports to Claude Code when ready to build Receives design bundles from Claude Design
Usage metering Shared pool with Claude.ai and Claude Code Shared pool with Claude.ai and Claude Design

The right mental model is a sequence: idea → prototype in Claude Design → implementation in Claude Code. The handoff is a single click in the Export menu — Claude packages the design intent into a bundle the coding agent picks up with one instruction.

For Magic Assistants

Where Claude Design fits in your work.

Reach for Claude Design when

  • A client needs a quick mockup or concept visual before committing to a designer.
  • You're building a pitch deck and want brand-aware slides faster than starting in Canva.
  • You need a one-pager, landing page draft, or campaign asset as a starting point.
  • You want to explore multiple layout directions and show options in a client call.

Hand off to Claude Code when

  • The mockup is approved and needs to become a real working page or app.
  • You need the design to pull live data or connect to a real backend.
  • The client's dev team needs to own and extend the code.

Claude Design draws from the same usage allowance as Cowork and Claude.ai chat. Heavy design sessions reduce your available Cowork capacity for the week. Budget accordingly.

Always review Claude Design outputs before sharing with a client. It's a research preview — output quality varies, especially for frontier design features (3D, video, shaders).

Current limitations

What to know before you rely on it.

  • Desktop access is via the sidebar only — Claude Design cannot be called from inside a Cowork task prompt.
  • Research preview — documented rough edges: dropped inline comments, save errors in compact view, lag with large codebases (link a subdirectory instead of the full repo).
  • No audit logs or admin usage reporting yet.
  • No data residency support — uploaded assets are stored persistently.
  • Usage resets weekly and sits per-user, not in a shared team pool.
  • Free plan excluded — requires Pro, Max, Team, or Enterprise.
  • No native Figma import or export — the Export menu does not produce a .fig file.

Usage is shared, not separate. Claude Design draws from the same weekly allowance as Cowork and Claude.ai chat — heavy design sessions reduce your Cowork capacity. Budget accordingly.

Access & plans

Getting started.

Claude Design is included in your Claude Team Standard seat — no additional subscription required. Open it from the Design icon in your Claude Desktop sidebar, or at claude.ai/design.

Quick-start checklist

  • Open Claude Design from the Desktop sidebar (or claude.ai/design) and confirm access with your Magic webmail account.
  • Create a new project and name it.
  • Ask your admin whether a design system has been published — if not, outputs will be generic.
  • Try your first prompt using the four-part structure: goal, layout, content, audience.
  • Iterate via chat, then try an inline comment on a specific canvas element.
  • Export a version, or try the Canva / Claude Code handoff at least once.

Enterprise admins must enable it manually under Organization Settings → Capabilities → Anthropic Labs. If you can't see Claude Design, email product-team@getmagicea.com.
